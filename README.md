# 거울빛 (MIRRORLIGHT) — 쌍거울의 무덤

> 한 문장 요약: **과거는 거울 빛이 닿는 곳에만 존재한다.**

정적 페이지, 서버 없음, Three.js r160 (CDN import map). 무대는 피라미드
매장군의 두 방(전실·매장실) 하나 — 문제 1 「매몰된 열쇠」와 문제 2
「사제의 끌과 벽감 금고」가 이 무대에서 이어진다.

## 실행

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 (three.js CDN 로드에 네트워크 필요)
```

`master`에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포한다
(`.github/workflows/pages.yml`).

- 조작: WASD 이동 · 마우스 시점 · `E` 상호작용 · `1`~`9` 물건 골라 들기 ·
  `G` 내려놓기(분신) · `F` 이동/복귀
- 거울: 바라보고 휠 = 회전. 두 청동 거울(A: 서쪽 끝→과거 1, B: 동쪽 끝→과거 2)은
  서로를 마주 본다.

## 빛의 법 (시각 규칙)

- **현재**에서는 거울빛 원뿔이 보이지 않는다 — 거울을 돌린 결과는 유리 속
  반사상(과거의 방에 드리운 빛줄기)으로만 확인한다.
- **과거**에서는 거울빛이 유일한 조명이다. 이동·상호작용이 가능한 원뿔 안만
  밝고, 빛 밖은 암흑이다. 원뿔 스포트라이트가 그림자를 드리우므로 벽이 빛을
  막고, 열린 통로로만 옆방에 새어 든다 — 개구 차폐 규칙의 물리적 대응물.
- 판정 수식(`conemath.js`)과 시각 조명은 같은 원뿔 파라미터를 공유한다.

## 아이템

집은 물건은 화면 하단의 **실물 3D 슬롯 바**에 들어간다 — 아이콘이 아니라
씬에서 쓰는 바로 그 소품 메쉬가 슬롯 안에서 돌아간다(`src/pyramid/itemhud.js`,
뷰포트·시저 오버레이 렌더). 여러 개를 동시에 들 수 있고, 슬롯의 숫자 배지에
맞춰 **숫자 키로 손에 들 물건을 고른다** — 새로 집으면 그것이 손에 들리고,
`E` 상호작용과 `G` 내려놓기는 손에 든 것을 쓴다. 맞지 않는 물건으로 시도하면
「여기에 쓰는 물건이 아니다」라고 안내하고, 맞는 물건을 들고 있으면 바꿔 들기
힌트까지 붙는다. 밝은 금테 슬롯 = 지금 손에 든 것(모두 내려놓아야 거울을
건넌다), 회색 테 = 현재 시대에 되찾아 품에 지닌 것.

## 두 문제

1. **매몰된 열쇠** — 현재의 열쇠는 무너진 천장 밑에 깔려 꺼낼 수 없다.
   붕괴 전 시대(과거 1)에서 남벽의 헐거운 벽돌을 `E` **길게 눌러 잡아당겨
   뽑고**(벽돌도 실물 아이템이 된다), 드러난 공동에 열쇠를 넣은 뒤 벽돌을
   골라 들어 도로 끼워야 한다 — **닫지 않은 공동은 도굴꾼들이 털어 간다.**
   닫아 두었다면 수천 년 뒤의 내가 같은 벽돌을 뽑아 되찾는다. 노출 방치는
   세월이 지운다.
2. **사제의 끌과 벽감 금고** — 끌은 더 먼 과거(과거 2)의 것이다. 화덕돌 밑
   공동으로만 과거 1에 도달한다(사제단은 화덕 밑을 살피지 않는다 — 그러나
   도굴꾼들은 들춘다: 구간별 은닉처 생존). 과거 1에서 끌로 벽감의 회반죽을
   뜯으면 그 「개방 상태」는 현재까지 흐른다. 벽감 속 청동 핀을 벽돌 뒤로
   보내 현재에서 되찾고, 굳게 닫힌 금고를 핀으로 열면 황금 스카라베 — 단,
   과거에서 금고문을 열어 둔 채 떠나면 도굴꾼들의 시대가 먼저 지나간다.

## 그래픽

- **재질:** Poly Haven CC0 PBR 텍스처 7세트(`assets/textures/`, 출처는
  `assets/textures/LICENSE.md`) — 사암 석축·석재 타일·화강암·잔해 바위·모래·
  회반죽. diff/normal + AO·러프니스·메탈 팩(arm).
- **장식:** 상형문자 음각 띠·석비·별 천장·날개 태양은 `src/pyramid/assets.js`가
  캔버스로 합성한다(높이맵 소벨 → 노멀맵). 안료는 과거에만 남아 있다.
- **조명:** ACES 톤매핑 + PCF 소프트 그림자 + PMREM 환경맵. 현재는 천장
  파공의 빛기둥과 도굴꾼의 손전등, 과거는 거울빛 원뿔뿐이다.
- **Node 테스트 호환:** 텍스처·캔버스 경로는 브라우저 가드 뒤에 있어
  스모크·검증은 단색 재질로 같은 씬 그래프를 얻는다.

## 검증

```bash
npm install --no-save three@0.160.0
npm test    # test/pyramid-smoke.mjs + src/pyramid/validate.js
```

- **기하:** 열쇠·벽돌 동시 커버 자세 0(릴레이 강제), 릴레이 공유 셀,

  도달 가능(소프트락 0).

미래(현재의 잔해)가 답안지로 먼저 대답한다.
