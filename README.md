# 타임즈 (TIMES) — 쌍거울의 무덤

> 과거는 거울 빛이 닿는 곳에만 있다.

과거를 비추는 두 개의 청동 거울을 오가며, 무덤 속 수수께끼를 풀고 탈출하는
1인칭 웹 퍼즐 게임입니다. 설치 없이 브라우저에서 바로 할 수 있습니다.

**플레이:** <https://ppco915.github.io/mirrorlight/>

(프로젝트 코드명은 MIRRORLIGHT, 게임 이름은 「타임즈」입니다. 첫 무대가
「쌍거울의 무덤」이고, 시작 화면의 지도에서 고릅니다.)

## 실행

- **웹(권장):** 위 주소로 접속해 지도에서 유적을 고르고 「모험하기」를 누릅니다.
- **로컬:**

  ```bash
  python3 -m http.server 8080
  # 브라우저에서 http://localhost:8080 (Three.js는 CDN에서 불러오므로 네트워크 필요)
  ```

- `master`에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포합니다
  (`.github/workflows/pages.yml`).
- 개발·시연용: 주소 뒤에 `?quick`을 붙이면 메뉴를 건너뛰고 바로 시작합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| 마우스 | 시점 돌리기 |
| W A S D | 걷기 |
| E | 조사하기 · 사용하기 (벽돌처럼 힘이 드는 것은 길게 누르기) |
| F | 거울로 들어가기 / 현재로 돌아오기 |
| G | 손에 든 물건 내려놓기 |
| 숫자 1 ~ 9 | 가진 물건 중 손에 쥘 것 고르기 |
| 마우스 휠 | (거울을 바라볼 때) 거울 돌리기 |
| H 길게 | 막혔을 때 힌트 (한 판에 세 번까지) |
| ESC | 일시 정지 |

집은 물건은 화면 아래 슬롯에 아이콘이 아니라 실제 3D 모형으로 표시됩니다.

## 규칙

1. **거울은 같은 방의 과거를 보여 줍니다.** 거울 가까이에서 `F`를 누르면 과거로
   들어갑니다. 서쪽 거울은 가까운 과거를, 동쪽 거울은 더 먼 과거를 비추며,
   어느 쪽이 먼저인지는 장면 속 단서로 알아낼 수 있습니다.
2. **과거에서는 거울 빛이 닿는 곳까지만 걸을 수 있습니다.** 거울을 바라보며
   휠을 굴리면 거울이 돌아가고 빛의 방향도 함께 바뀝니다. 과거에서는 이 빛이
   유일한 조명이라, 밝은 범위가 곧 움직일 수 있는 범위입니다. 빛은 벽을 넘지
   못하고, 열린 통로로만 옆방에 들어갑니다.
3. **물건은 거울을 통과하지 못합니다.** 물건을 손에 든 채로는 어느 방향으로도
   건널 수 없습니다. 과거의 물건을 현재로 가져오려면 벽 틈처럼 오래 견디는
   자리에 숨겨 두고, 현재에서 같은 자리를 열어 꺼냅니다. 바닥에 두고 온 것은
   시간이 지나는 동안 사라지고, 숨긴 자리도 시대에 따라 안전하지 않을 수
   있습니다.
4. **과거에서 바꾼 것은 현재에 남습니다.** 과거에서 연 문과 뜯어낸 벽은 현재에도
   그 모습 그대로입니다. 반대로 현재에서 한 일이 과거를 바꾸지는 못합니다.

## 세 가지 수수께끼

1. **묻힌 열쇠** — 무너진 천장 밑에 깔린 열쇠를, 아직 무너지지 않은 과거를
   거쳐 손에 넣습니다.
2. **사제의 끌과 벽 속 금고** — 더 먼 과거의 도구를 가까운 과거로 보내 벽을
   열고, 그 결과를 현재에서 거둡니다.
3. **신의 이름** — 금고에서 얻은 보물을 벽화에 대어 보면, 가짜 문을 여는
   세 글자가 드러납니다.

자세한 풀이는 스포일러라 적지 않습니다. 게임 안의 힌트(`H` 길게)가 막힌
단계를 짚어 줍니다.

## 화면과 소리

- **재질:** Poly Haven의 무료(CC0) PBR 텍스처 7세트 — 사암 벽돌, 석재 타일,
  화강암, 잔해 바위, 모래, 회반죽 2종.
- **그림:** 아누비스 벽화, 상형문자 띠, 석판, 글자 다이얼은 코드로 직접
  그립니다. 무늬를 흑백 명암으로 그린 뒤 조명 계산에 쓰는 노멀 맵으로 바꿔,
  손전등을 비스듬히 비추면 새긴 무늬에 그늘이 집니다.
- **조명:** 현재는 천장 구멍으로 드는 빛과 손전등뿐이고, 과거는 거울에서 나오는
  빛기둥뿐입니다. 판정에 쓰는 수식과 화면의 빛이 같은 값을 공유하므로, 눈에
  보이는 밝은 범위와 실제로 움직일 수 있는 범위가 늘 일치합니다.
- **소리:** OpenGameArt의 무료 음원을 썼습니다(대부분 CC0, 일부 CC-BY로 출처
  표기). 음원을 불러오기 전이나 실패한 환경에서는 브라우저 안에서 합성한
  소리가 대신합니다.

## 자동 검증

```bash
npm install --no-save three@0.160.0
npm test    # test/pyramid-smoke.mjs + src/pyramid/validate.js
```

- **기하 검사:** 거울 빛이 열쇠·벽돌 같은 목표 지점에 실제로 닿는지, 상호작용
  지점에 충분한 여유가 있는지, 한 각도에서 두 목표가 동시에 잡혀 문제가
  쉬워지지 않는지를 수치로 확인합니다.
- **막힘 검사:** 플레이어가 도달할 수 있는 모든 진행 상태(112가지)를 자동으로
  탐색해서, 어떤 순서로 행동해도 끝까지 풀 수 있음을 확인합니다.

## 참고한 게임

- **Viewfinder** — 비친 이미지가 현실 공간이 되는 발상.
- **The Art of Reflection** — 거울을 문으로 쓰는 1인칭 퍼즐.
- **Shady Part of Me / In My Shadow** — 정해진 영역 안에서만 움직이는 분신.
- **Day of the Tentacle / The Past Within** — 과거에서 보낸 것이 미래에 도착하는 구조.

이 게임의 다른 점: 빛이 닿는 곳만 과거가 되고, 물건은 숨긴 자리를 통해서만
시간을 건너며, 무너진 현재의 모습이 그대로 힌트가 됩니다.
