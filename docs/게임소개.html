MIRRORLIGHT — 해커톤 제출용 게임 소개 문서

쌍거울의 무덤

과거를 비추는 두 개의 청동 거울을 오가며, 무덤 속 수수께끼를 풀고 탈출하는 1인칭 웹 퍼즐 게임입니다.

1. 게임 방법

배경과 목표

주인공은 보물을 노리고 옛 피라미드에 숨어든 도굴꾼입니다. 게임이 시작되면 천장이 무너지며 주인공이 무덤 안에 갇힙니다. 방의 양쪽 끝에는 청동 거울이 하나씩 서 있고, 두 거울은 서로 다른 시대의 과거를 비춥니다. 거울 속으로 들어가 과거에서 한 행동은, 오랜 시간이 지난 현재에 그 결과가 그대로 남습니다. 이 원리를 이용해 세 가지 수수께끼(묻힌 열쇠, 두 과거에 나뉘어 있는 도구, 가짜 문의 세 글자)를 차례로 풀고, 보물을 손에 넣은 뒤, 가짜 문을 열어 무덤을 빠져나가는 것이 목표입니다.

핵심 규칙

  1. 거울은 같은 방의 과거를 보여 줍니다. 거울 가까이에서 F 키를 누르면 거울 속 과거로 들어가고, 과거에서 다시 F 키를 누르면 현재로 돌아옵니다.
  2. 과거에서는 거울 빛이 닿는 곳까지만 걸을 수 있습니다. 거울을 바라보며 마우스 휠을 굴리면 거울이 돌아가고, 빛이 비추는 방향도 함께 바뀝니다. 가고 싶은 곳에 미리 빛을 비춰 두어야 합니다.
  3. 물건은 거울을 통과하지 못합니다. 물건을 손에 든 채로는 어느 방향으로도 거울을 건널 수 없습니다. 과거의 물건을 현재로 가져오려면, 과거에서 벽 틈처럼 오래 견디는 자리에 숨겨 두고, 현재에서 같은 자리를 열어 꺼내야 합니다. 바닥에 그냥 두고 오면 시간이 지나는 동안 사라집니다.
  4. 과거에서 바꾼 것은 현재에 남습니다. 과거에서 연 문, 뜯어낸 벽은 현재에도 그 모습 그대로입니다. 반대로 현재에서 한 일이 과거를 바꾸지는 못합니다.

조작 방법

마우스 이동시점 돌리기
W / A / S / D걷기
E조사하기 · 사용하기 (벽돌처럼 힘이 드는 것은 길게 누르기)
F거울로 들어가기 / 현재로 돌아오기
G손에 든 물건을 바닥에 내려놓기
숫자 1 ~ 9가지고 있는 물건 중 손에 쥘 것 고르기
마우스 휠(거울을 바라볼 때) 거울 돌리기
ESC마우스 잠금 풀기 (화면을 클릭하면 다시 잠깁니다)

종료 조건

  • 승리: 세 수수께끼를 모두 풀고 가짜 문을 열어 무덤을 나가면, 탈출 장면과 함께 게임이 끝납니다. 마지막 화면을 클릭하면 처음부터 다시 시작할 수 있습니다.
  • 패배 없음: 죽거나 실패로 끝나는 경우는 없습니다. 또한 어떤 순서로 행동해도 더 이상 풀 수 없는 상태에 빠지지 않도록 설계했고, 모든 진행 경로를 자동 검사 도구로 확인했습니다.

2. 실행 방법

웹에서 바로 실행 (권장 — 설치 필요 없음)

플레이 링크: https://ppco915.github.io/mirrorlight/
  1. 위 주소를 데스크톱 브라우저로 엽니다.
  2. 첫 화면 아래 글자가 「로딩 중…」에서 「클릭해서 계속」으로 바뀌면 화면을 클릭합니다.
  3. 바로 게임이 시작됩니다. 계정, 설치, 결제가 전혀 필요 없습니다.

내 컴퓨터에서 실행 (선택)

  1. 소스 코드를 내려받습니다: git clone https://github.com/ppco915/mirrorlight
  2. 내려받은 폴더에서 간단한 웹 서버를 켭니다: python3 -m http.server 8080
  3. 브라우저에서 http://localhost:8080 을 엽니다.

따로 설치하거나 빌드할 것이 없습니다. 필요한 라이브러리(Three.js)는 웹에서 자동으로 불러옵니다.

권장 환경

  • 데스크톱 크롬(Chrome) 최신 버전 — 마우스가 꼭 필요하므로 데스크톱을 권장합니다.
  • 소리를 켜고 하시기를 권장합니다. 발소리, 돌 가는 소리 등이 진행에 도움을 줍니다.
