MIRRORLIGHT — 해커톤 제출용 게임 소개 문서

쌍거울의 무덤

서로 다른 과거를 비추는 두 청동 거울을 이용해, 무덤의 수수께끼를 풀고 빠져나가는 1인칭 웹 퍼즐 게임입니다.

1. 게임 방법

배경과 목표

주인공은 보물을 노리고 옛 피라미드에 숨어든 도굴꾼입니다. 그런데 게임이 시작되자마자 천장이 무너지고, 무덤 안에 갇히고 맙니다. 방 양쪽 끝에 서 있는 청동 거울은 각각 다른 시대의 과거로 이어집니다. 과거에서 문을 열거나 물건을 숨겨 두면, 오랜 시간이 흐른 현재에도 그 흔적이 남습니다. 이를 활용해 묻힌 열쇠, 두 과거에 나뉘어 있는 도구, 가짜 문의 세 글자에 관한 수수께끼를 풀고 무덤을 탈출해야 합니다.

핵심 규칙

  1. 거울은 같은 방의 과거를 보여 줍니다. 거울 앞에서 F 키를 누르면 과거로 넘어갑니다. 돌아올 때도 거울 앞에서 F 키를 누르면 됩니다.
  2. 과거에서는 거울 빛이 닿는 곳까지만 갈 수 있습니다. 거울을 보고 마우스 휠을 굴리면 거울과 빛줄기가 함께 돌아갑니다. 먼저 가고 싶은 곳으로 빛을 옮겨 놓은 뒤 거울 안으로 들어가야 합니다.
  3. 물건을 든 채로 거울을 건널 수는 없습니다. 과거의 물건을 현재에서 쓰려면 벽 틈처럼 오랜 시간 남아 있을 곳에 숨겨야 합니다. 그런 다음 현재로 돌아와 같은 자리에서 꺼낼 수 있습니다. 바닥에 그냥 놓고 오면 시간이 흐르면서 사라집니다.
  4. 과거에서 일어난 일은 현재에 남습니다. 과거에서 열어 둔 문이나 뜯어낸 벽은 현재에서도 그 상태입니다. 단, 현재에서 한 행동이 과거에 영향을 주지는 않습니다.

조작 방법

마우스 이동시점 돌리기
W / A / S / D걷기
E조사하기 · 사용하기 (벽돌처럼 힘이 드는 것은 길게 누르기)
F거울로 들어가기 / 현재로 돌아오기
G손에 든 물건을 바닥에 내려놓기
숫자 1 ~ 9가지고 있는 물건 중 손에 쥘 것 고르기
마우스 휠(거울을 바라볼 때) 거울 돌리기
ESC마우스 잠금 풀기 (화면을 클릭하면 다시 잠깁니다)

종료 조건

  • 승리: 세 수수께끼를 풀고 가짜 문으로 탈출하면 게임이 끝납니다. 마지막 화면을 클릭해 처음부터 다시 플레이할 수 있습니다.
  • 패배 없음: 죽거나 실패 화면으로 끝나지 않습니다. 순서를 달리해도 퍼즐을 더 풀 수 없는 상태가 되지 않는지, 가능한 진행 경로를 자동 검사로 확인했습니다.

2. 실행 방법

웹에서 바로 실행 (권장 — 설치 필요 없음)

플레이 링크: https://ppco915.github.io/mirrorlight/
  1. 위 주소를 데스크톱 브라우저로 엽니다.
  2. 첫 화면 아래의 「로딩 중…」이 「클릭해서 계속」으로 바뀌면 화면을 클릭합니다.
  3. 바로 게임이 시작됩니다. 계정을 만들거나 따로 설치할 필요는 없습니다.

내 컴퓨터에서 실행 (선택)

  1. 소스 코드를 내려받습니다: git clone https://github.com/ppco915/mirrorlight
  2. 내려받은 폴더에서 간단한 웹 서버를 켭니다: python3 -m http.server 8080
  3. 브라우저에서 http://localhost:8080 을 엽니다.

별도 설치나 빌드 과정은 없습니다. Three.js를 비롯한 필요한 라이브러리는 실행할 때 웹에서 불러옵니다.

권장 환경

  • 데스크톱용 최신 크롬(Chrome)을 권장합니다. 마우스를 사용하는 게임이라 모바일에서는 플레이하기 어렵습니다.
  • 가능하면 소리를 켜고 플레이해 주세요. 발소리나 돌 갈리는 소리가 퍼즐을 파악하는 데 도움이 됩니다.
